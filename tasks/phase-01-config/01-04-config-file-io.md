# 01-04 · Config file I/O

**Phase:** 01 — Config · **Agent:** A · **Size:** S
**Prerequisites:** `01-02`, `01-03`
**Reference:** `docs/02-data-model.md` §9, `docs/12-decisions.md` §5

## Goal
Read and write `config.toml` from the binary, with atomic writes, correct permissions, and a
first-run file that is worth reading. `loxia-core` stays I/O-free; this code lives in the binary.

## Files
- `crates/loxia-player/src/bootstrap.rs`

## Specification

```
pub fn load(paths: &Paths) -> (Config, Vec<ConfigWarning>)
pub fn save(paths: &Paths, cfg: &Config) -> Result<()>
```

**Load:**
1. If the file is absent, write the first-run default (below) and return
   `Config::default()` plus an `Info` warning naming the created path.
2. Read, `migrate`, deserialize, `validate`. A **parse error** is not fatal: rename the file to
   `config.toml.bad`, write a fresh default, and return a `Warning` explaining what happened. A user
   with a typo must still get a working player.

**Save (atomic):** write `config.toml.tmp` in the same directory → `fsync` → set mode `0600` on Unix
→ rename over the target. Setting the mode before the rename means the token is never briefly
world-readable.

**Permission check on load (Unix):** if the existing file's mode has any group or other bit set,
emit a `Warning`: `config.toml is readable by other users; it contains your access token`. Do not
change the mode silently — the user may have deliberate reasons.

**First-run file** is generated by serializing `Config::default()` and prepending a commented
header: what the file is, where the docs are, and a commented-out `[[servers]]` block showing
`url`, `user_id`, `access_token`, and a `[servers.custom_headers]` example. Round-tripping this file
must be lossless.

Callers must never log the `Config` with `{:?}` on a path that includes tokens; `ServerConfig`'s
manual `Debug` (task `01-01`) already redacts, and a test asserts it.

## Acceptance
Tests in `bootstrap.rs`, using `tempfile`:
- `first_run_creates_config_and_returns_defaults`
- `first_run_file_roundtrips` — read back the generated file; it equals `Config::default()`.
- `corrupt_config_is_quarantined_and_replaced` — `config.toml.bad` exists afterwards and load
  succeeds.
- `save_is_atomic` — no `.tmp` file remains after a successful save.
- `save_sets_0600_on_unix` (`#[cfg(unix)]`)
- `world_readable_config_warns` (`#[cfg(unix)]`)
- `save_then_load_roundtrips`
